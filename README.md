# Fish Tab

一个 Chrome 浏览器侧边栏扩展，按域名分组管理打开的标签页，附带最近关闭恢复、缩略图预览和搜索能力。

## 功能

- **按域名分组**：所有打开标签按域名归类，每组可一键折叠/展开/全部关闭。
- **最近关闭**：列出最近关闭的标签和窗口，点击即可恢复（基于 `chrome.sessions`）。
- **搜索过滤**：按域名、标题或 URL 实时过滤，支持 Esc 清空。
- **悬停缩略图**：鼠标悬停在 favicon 上展示标签预览图。
- **多窗口感知**：跟踪当前聚焦窗口，仅对用户实际在看的标签维护新鲜缩略图。

## 安装

1. 克隆或下载本仓库。
2. 打开 `chrome://extensions`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选中本仓库根目录（含 `manifest.json` 的那一层）。
4. 点击工具栏的扩展图标即可在侧边栏打开。

需要 Chrome 114 或更高版本（依赖 `sidePanel` API）。

## 使用

| 操作 | 效果 |
| --- | --- |
| 点击任意标签行 | 切到该标签 |
| 点击域名行 | 折叠/展开该分组 |
| 顶部三横按钮 | 全部折叠/展开 |
| 顶部刷新按钮 | 重新读取标签列表 |
| 顶部齿轮按钮 | 打开设置面板 |
| 鼠标悬停 favicon | 显示页面缩略图 |
| 在「最近关闭」点击行或 ↺ 按钮 | 恢复对应会话 |
| 搜索框 Esc | 清空当前查询 |

## 设置

设置项保存在 `chrome.storage.local`，对所有窗口实时生效。

### 缩略图刷新策略

| 时机 | 行为 | 是否可关 |
| --- | --- | --- |
| 切到某个标签时 | 立即截图 | 默认开启，不可关 |
| 切到标签后 1.5 秒 | 再截一次（捕获渲染完毕的状态） | 默认开启，不可关 |
| 标签加载完成且仍是活动标签 | 重新截图 | 默认开启，不可关 |
| 停留在活动标签期间 | 按设定频率周期性重截 | **可在设置中开关** |

**定时刷新当前标签**（默认开启）：开启后，活动标签每隔 10 / 15 / 30 / 60 秒（可选）重截一次。仅在窗口聚焦时执行；切到其他应用或窗口会自动暂停。

> 由于 Chrome 的 `chrome.tabs.captureVisibleTab` 只能截取当前可见标签，无法在用户切走的瞬间为旧标签补一张图。定时刷新就是用来逼近"切走前一刻"那张图的折中方案。

## 隐身模式

当前 manifest 未声明 `incognito`，所以扩展默认在隐身窗口中**不可见**也**不可管理**隐身标签。如需启用，请在 `chrome://extensions` 找到 Fish Tab 的「详情」页打开「在隐身模式下启用」（注意：会与普通窗口共用同一个侧边栏实例和缓存）。

## 项目结构

```
manifest.json                 MV3 配置：sidePanel + 全站 host_permissions
src/
├── background/
│   ├── service-worker.js     消息路由、标签事件监听、聚焦/激活跟踪、定时截图
│   ├── tabs.js               标签查询/激活/关闭、会话恢复
│   └── captures.js           captureVisibleTab + JPEG 缩放 + session 缓存
├── sidepanel/
│   ├── sidepanel.html        侧边栏布局
│   ├── sidepanel.css         样式
│   └── sidepanel.js          交互、渲染、设置面板
└── shared/
    ├── messages.js           SW ↔ sidepanel 消息类型常量
    └── settings.js           设置默认值与校验（SW、sidepanel 共用）
```

## 数据与存储

| 键 | 位置 | 用途 |
| --- | --- | --- |
| `fishTabSettings` | `storage.local` | 用户偏好（缩略图刷新开关与间隔） |
| `fishTabCollapsedDomains` | `storage.local` | 已折叠的域名集合 |
| `fishTabCaptures` | `storage.session` | 缩略图缓存（最多 40 项，会话内有效） |

`storage.session` 在浏览器重启或扩展重载后清空——这是设计预期：缩略图是临时数据，不长期持久化。

## 已知限制

- 隐身模式下的标签默认不可见（见上文）。
- Service Worker 在 MV3 下可能被 Chrome 暂停；定时截图依赖标签/窗口事件唤醒，长时间无操作时会间歇暂停，下次切换时恢复。
- `captureVisibleTab` 只能对聚焦窗口的活动标签生效；切到非 Chrome 应用时定时刷新会暂停。
